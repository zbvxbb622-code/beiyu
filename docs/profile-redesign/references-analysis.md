# 「我的」个人主页 · 业界参考分析与设计应用

> 目标：参考业界优秀同类项目 / 原型，提取设计亮点与交互模式，复刻并优化当前「我的」页，达到专业级水准。
> 约束：沿用现有 App 设计语言（深色酒吧底、品牌粉 CTA、半透明玻璃面板、系统字体、lucide 线性图标），不换美术风格。

## 一、参考案例与亮点提取

### 1. 同类酒饮 App（BarGenius / Mixel / Cocktail Flow / Boozle / BarShelf / Highball）
- **Cocktail Flow**："先用眼喝酒"——每款酒都用高清大图呈现，视觉效果是第一卖点。
- **BarShelf（4.9★）**：把酒柜做成"数字藏酒阁"，酒瓶照片 + 剩余量滑块 + 每周洞察 + 可分享的精美卡片；"像为真正藏家做的"。→ **个人主页应强调"我的酒柜/收藏"的策展感与分享性**。
- **Mixel / Highball**："酒柜里有什么就能调什么"的个性化推荐引擎；Highball 被称为"鸡尾酒里的 Apple"——极简、视觉惊艳。→ **加入"AI 调酒师为你推荐"智能卡**。
- **Boozle**："根据心情随机推荐 + 一键记录"，交互顺滑直观。

### 2. Untappd（社交打卡标杆，~900 万用户）
- **徽章系统（Badges）**：把"喝过的酒 / 到过的店 / 连续打卡"做成可收集的数字成就徽章（"像啤酒界的宝可梦"），强驱动力、强专业感。→ **加入"成就徽章"横向滑动条**。
- **个人档案展示**：徽章、喝过的酒、挑战进度一目了然；Toast/Cheers 等轻社交互动。
- **口味画像 → 个性化推荐**：基于历史 check-in 推荐。

### 3. 个人主页交互范式
- **Apple Music 收缩式头部**（SwiftUI 实战）：滚动时大图 banner 优雅收缩、头像缩放、文字缩放、Tab 吸顶并做匹配动画；核心是"读取滚动偏移驱动头部高度/模糊/缩放"。→ **Hero 做视差 + 滚动收缩模拟**。
- **Glassmorphism（iOS 26 / macOS Tahoe / Robinhood）**：磨砂玻璃卡 = 背景模糊 + 半透明 + 细描边 + 10–30% 实色叠层保可读性；要点：玻璃后面要有"东西"（景深）、勿滥用、用间距与对比建立层级。→ **stat 条 / 推荐卡 / 设置用玻璃卡，叠在模糊酒图背景上制造景深**。

### 4. Spotify / Airbnb（高级感与信息架构）
- **Spotify 暗色 UI**：纯黑底让封面与按钮"跳出来"；高对比强调色（绿=播放）；**点赞微交互即时反馈**；导航极简、图标遵循熟悉范式。→ **保留深色底 + 品牌粉强调；开关/点赞做即时状态反馈**。
- **Airbnb**：低信息密度、充足留白"呼吸感"；图像为主文字为辅；社会证明（评分/徽章）降低认知负担；底部导航跨平台一致。→ **降低密度、加留白；用"已认证调酒师"等信任标记；底部 5 Tab 保持一致**。

## 二、应用到当前「我的」页的设计决策

| 参考来源 | 提取的模式 | 在本页的落地 |
|---|---|---|
| Cocktail Flow / BarShelf | 图像主导、酒柜策展感 | Hero 用模糊酒图背景 + 大图酒卡；"酒柜"内容做玻璃卡网格 |
| BarShelf / Mixel / Highball | 个性化推荐引擎 | 新增「AI 调酒师·今晚为你推荐」智能卡（基于酒柜内容） |
| Untappd | 成就徽章系统 | 新增「成就」横向滑动徽章条（数字收藏品，强专业感+粘性） |
| Apple Music | 收缩式视差头部 | Hero 滚动收缩 + 头像缩放 + 模糊随滚动增强（JS 模拟） |
| Glassmorphism | 磨砂玻璃卡 + 景深 | stat 条 / 推荐卡 / 设置 / 内容卡统一玻璃材质，叠在模糊酒图上 |
| Spotify | 微交互即时反馈 | Tab 切换淡入、开关 on/off、点赞/Cheers 即时态、按钮 :active 缩放 |
| Airbnb | 低密度 + 留白 + 信任标记 | 放大间距、加"已认证调酒师"徽标、底部导航保持一致 |

## 三、视觉与交互升级清单（相对旧版）
1. **景深玻璃背景**：Hero 与背景酒图模糊层叠加，玻璃卡浮于其上，消除"平"的观感。
2. **视差收缩头部**：滚动时头部收缩、头像与文字缩放、模糊增强——高级 App 标志性交互动效。
3. **成就徽章条**：把"社交/打卡/收藏"转化为可收集徽章，显著提升专业感与留存驱动。
4. **AI 推荐卡**：从"展示数据"升级为"主动服务"，贴合酒饮 App 最佳实践。
5. **酒柜剩余量条**（BarShelf 启发）：设置里的「本地数据保险箱」用细进度条表达占用，替代枯燥文字。
6. **信任标记 + 低密度留白**：已认证徽章、更大行距与分隔，呼吸感更强。
7. **统一微交互**：Tab 淡入、开关、点赞、按钮反馈一致且顺滑。
